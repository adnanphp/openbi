# OpenBI

OpenBI is an end-to-end open-source Business Intelligence and Analytics platform that ingests retail transaction data, models it into a star-schema warehouse in PostgreSQL, exposes KPIs and ML-driven insights (customer segmentation and sales forecasting) through Apache Superset dashboards, and serves metrics via a FastAPI layer. The project demonstrates the full modern data stack: Python ETL, SQL analytics, data warehousing, BI visualization, machine learning, and containerized deployment — all built entirely with free and open-source tools.
